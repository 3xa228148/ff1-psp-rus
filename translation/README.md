# Папка перевода

Здесь лежит весь русский перевод Final Fantasy (PSP). Русификатор `ff1_rus.py`
собирает из этих файлов игровые файлы и вставляет их в образ пользователя.

| Папка / файл | Что внутри |
|---|---|
| `text/dialogs/` | диалоги и сцены, по одному файлу на локацию |
| `text/menus/` | меню, экраны, пролог, эпилог |
| `text/items_magic/` | названия и описания предметов, оружия, брони и магии |
| `text/battle/` | бой: команды, имена монстров, их атаки, сообщения |
| `text/bestiary/` | бестиарий |
| `text/credits/` | титры |
| `text/gallery/` | галерея |
| `text/debug/` | отладочные меню разработчиков (в обычной игре не видны) |
| `text/system/save_messages.txt` | системные сообщения PSP при сохранении/загрузке |
| `fonts/` | шрифты перевода: `.FIF` (таблица глифов), `.GIM` (атлас), `.charmap.txt` (какой символ под каким номером) |
| `graphics/` | исправленные участки картинок |
| `code/boot_patch.txt` | правка кода игры (меню выбора языка) |
| `manifest.json` | инструкции сборки, создаётся `tools/export_project.py` |

## Формат текстов

```
# комментарии (только в начале файла)
@mode 1
=== 0 ===
Текст первой записи.
Можно в несколько строк.{c3}
Новая страница диалога.
=== 1 ===
...
```

- Номера записей `=== N ===` менять нельзя.
- `{c3}` в диалогах — новая страница (ожидание кнопки).
- `{cN}` — прочие служебные коды игры (значки предметов и т. п.), не удалять.
- `{gN}` — глиф шрифта без обычного символа.
- `{t}`, `{noend}` — технические метки, встречаются в нескольких служебных строках.
- `{{` — символ `{`.
- `@mode 3` (меню выбора языка, имена, музыка): строки идут тройками —
  1-я и 2-я для режима English, 3-я для русского.

Писать можно только символами, которые есть в шрифте этого файла
(путь к таблице символов указан в шапке файла). Похожие латинские и русские буквы
(А/A, В/B, Е/E, К/K, М/M, Н/H, О/O, Р/P, С/C, Т/T, Х/X, а/a, е/e, о/o, р/p, с/c, у/y, х/x)
подставляются автоматически.

## Формат таблицы символов (`*.charmap.txt`)

```
номер<TAB>символ
```

`<пробел>` — пробел, `<конец>` — конец строки, пустое значение — служебный глиф.
Если вы перерисовали глиф в атласе `.GIM`, исправьте и символ в таблице.
